Bibliothèque en Ligne

========================================
1. PRÉSENTATION GÉNÉRALE
========================================

Ce projet est une application web de gestion de bibliothèque
permettant aux utilisateurs de rechercher, consulter et gérer
une collection de livres en ligne.

Technologies : HTML5, CSS3, JavaScript, PHP 8.x, MySQL 8.x

========================================
3. DÉMONSTRATION DES FONCTIONNALITÉS
========================================

3.1 AUTHENTIFICATION
--------------------
- Page de connexion : login.html
- Page d'inscription : register.html
- 2 rôles : admin et lecteur
- Sessions sécurisées avec PHP
- Hachage des mots de passe (password_hash)

3.2 PAGE D'ACCUEIL (Public)
-----------------------------
- Présentation de la bibliothèque
- Barre de recherche en temps réel
- Grille de livres avec badges exemplaires
- Bouton "Voir détails" pour chaque livre

3.3 DÉTAILS D'UN LIVRE
-----------------------
- Affichage complet : titre, auteur, édition, description
- Nombre d'exemplaires disponibles
- Boutons : Ajouter à la liste, Modifier, Supprimer
- Navigation retour

3.4 CRUD COMPLET
-----------------
- Ajouter : formulaire avec validation
- Modifier : formulaire pré-rempli
- Supprimer : avec confirmation
- Liste : affichage en grille

3.5 LISTE DE LECTURE
---------------------
- Livres empruntés par l'utilisateur
- Dates d'emprunt et de retour
- Possibilité de retirer un livre

3.6 INTERFACE ADMINISTRATION
-----------------------------
- Statistiques : nombre de livres, emprunts, utilisateurs
- Tableau de gestion des livres (modifier/supprimer)
- Liste des utilisateurs avec leurs rôles
- Accès réservé aux administrateurs

========================================
4. SÉCURITÉ
========================================

- Requêtes préparées PDO (anti injection SQL)
- htmlspecialchars() (anti XSS)
- Vérification des rôles côté serveur
- Sessions sécurisées
- Validation des entrées

========================================
5. ÉCOCONCEPTION
========================================

- Pas de frameworks externes lourds
- CSS vanilla (pas de Bootstrap)
- JavaScript vanilla (pas de jQuery)
- Requêtes SQL optimisées
- Assets légers

========================================
6. WORKFLOW GIT
========================================

Branches :
- main : version stable
- develop : développement
- feature/* : nouvelles fonctionnalités

Commits : messages clairs et concis
Pull requests : revue de code avant merge
Tags : versionnage des releases
