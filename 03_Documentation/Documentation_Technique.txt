========================================
3. BASE DE DONNÉES
========================================

3.1 Tables
----------

livres :
  id INT AUTO_INCREMENT PRIMARY KEY
  titre VARCHAR(100)
  auteur VARCHAR(100)
  description TEXT
  maison_edition VARCHAR(100)
  nombre_exemplaire INT

lecteurs :
  id INT AUTO_INCREMENT PRIMARY KEY
  nom VARCHAR(100)
  prenom VARCHAR(100)
  email VARCHAR(100) UNIQUE

liste_lecture :
  id INT AUTO_INCREMENT PRIMARY KEY
  id_livre INT (FK → livres.id)
  id_lecteur INT (FK → lecteurs.id)
  date_emprunt DATE
  date_retour DATE

3.2 Relations
--------------
- liste_lecture.id_livre → livres.id (N..1)
- liste_lecture.id_lecteur → lecteurs.id (N..1)

========================================
4. API PHP
========================================

4.1 api_livres.php
-------------------
Actions :
- list : liste tous les livres
- search?q= : recherche par titre/auteur
- get&id= : détail d'un livre
- add (POST) : ajouter un livre
- update (POST) : modifier un livre
- delete (POST) : supprimer un livre

4.2 api_liste.php
------------------
Actions :
- list : liste de lecture de l'utilisateur
- add (POST) : ajouter à la liste
- remove (POST) : retirer de la liste
- check&id_livre= : vérifier si dans la liste

6. INSTALLATION
========================================

Prérequis :
- Laragon (PHP 8.x + MySQL)
- Navigateur moderne

Étapes :
1. Copier 04_Code_Source/ dans C:\laragon\www\bibliotheque\
2. Ouvrir phpMyAdmin (http://localhost/phpmyadmin)
3. Importer sql/schema.sql
4. Ouvrir http://localhost/bibliotheque/

Identifiants MySQL :
- Hôte : localhost
- Utilisateur : root
- Mot de passe : (vide)
- Base : bibliotheque
